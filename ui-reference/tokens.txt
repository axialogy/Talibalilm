# Talibalim — design tokens
#
# PROVENANCE: derived from a full-page screenshot of the live WordPress site
# (Institut Talib Alim) supplied by the client. The `ui-reference/` directory
# described in the build spec was never delivered, so these stand in for the
# extracted `tokens.txt` until the real one arrives. They were sampled by eye
# from the rendered page, not read out of the stylesheet — treat any value as
# correctable, and correct it HERE, then mirror it into
# src/app/globals.css @theme. Nothing else in the codebase hardcodes a colour.

The logo, rating stars, hairlines on course covers. Never a filled button:

### Ink — text
A green-black, not #000. Pure black next to emerald on white reads cold.
ink         #16221f   headings, primary text
ink-soft    #2b3b38   secondary
ink-muted   #637471   body copy, captions, inactive nav

### Surfaces
background  #ffffff
surface     #f2f7f6   section backgrounds, cards on white
accent      #e9f7f3   tinted callouts

### Hero wash
Linear gradient, 135deg: #edf2f1 -> #f5f8f7 -> #e7eeec
Bottom-right corner radius 72px (mobile) / 140px (lg and up).

## Type

Display   Poppins        600 / 500 — headings, buttons, nav
Body      Geist          400 / 500 — paragraphs, form fields
Arabic    Tajawal        400 / 500 / 700 — all Arabic text, and every heading
                         when locale = ar (Poppins has no Arabic glyphs)

All three self-hosted from /public/fonts as woff2. Nothing is fetched from a
font CDN, so no text is render-blocked on a third party.

Scale (clamped, fluid between the two ends):
h1        clamp(2rem, 5.2vw, 3.125rem)   600   leading 1.14   tracking -0.03em
h2        clamp(1.75rem, 3.2vw, 2.125rem) 600  leading 1.18   tracking -0.02em
h3        1.0625rem                       600   leading 1.35
body      0.9375rem                       400   leading 1.65
small     0.8125rem                       400   leading 1.55
eyebrow   0.6875rem  uppercase  tracking 0.18em  500
